# Learning Plan (Prompt #14)

Prompt asal: "Create a step-by-step learning plan to master [your skill] from beginner to advanced level."

## Langkah
1. Tanya/andaikan: tahap semasa, masa seminggu, matlamat akhir, gaya belajar dan bajet.
2. Bahagikan kepada peringkat: Asas → Pertengahan → Mahir.
3. Setiap peringkat mesti ada projek praktikal, bukan teori sahaja.

## Format jawapan
- **Matlamat & anggaran tempoh**
- **Peringkat 1 / 2 / 3** — untuk setiap satu: topik, sumber (percuma dulu), projek praktikal, tanda sudah lulus peringkat
- **Jadual mingguan** (jadual: Minggu | Fokus | Tugasan | Jam)
- **Kesilapan biasa** dan cara elak
- **Langkah pertama hari ini**
