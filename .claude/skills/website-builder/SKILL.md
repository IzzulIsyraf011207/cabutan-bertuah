# Website Builder (Prompt #12)

Prompt asal: "Create a complete HTML, CSS and JavaScript code for a modern, responsive website for [your niche]."

## Langkah
1. Kenal pasti niche, tujuan laman (jualan, info, portfolio), audiens, bahasa, warna/brand dan bahagian yang perlu.
2. Jika skill `ui-ux-pro-max` tersedia, ikut panduan reka bentuknya untuk gaya premium.
3. Struktur lalai: Header/nav → Hero (tajuk + CTA) → Manfaat/ciri → Bukti sosial/testimoni → Harga/tawaran → FAQ → CTA akhir → Footer.
4. Mobile-first, responsif (≤ 375px hingga desktop), aksesibel (kontras, alt text, label), laju (tiada library berat tanpa sebab).
5. Uji di pelayar (Playwright tersedia) pada saiz telefon dan desktop sebelum serah.

## Format jawapan
- Fail `index.html`, `styles.css`, `script.js` (atau satu fail jika diminta)
- Cara buka/deploy (contoh GitHub Pages)
- Senarai bahagian yang pengguna perlu tukar (teks, gambar, link WhatsApp, dsb.)
