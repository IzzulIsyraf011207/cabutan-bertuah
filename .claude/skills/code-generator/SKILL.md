# Code Generator (Prompt #10)

Prompt asal: "Write clean, efficient and well-commented code for [your requirement] in [programming language]."

## Langkah
1. Fahami keperluan, input/output dan kekangan. Kalau dalam repo, baca kod sekitar dulu dan ikut gaya, struktur folder dan library sedia ada.
2. Pilih pendekatan paling ringkas yang memenuhi keperluan. Jangan tambah ciri yang tidak diminta.
3. Tulis kod dengan nama yang jelas, komen hanya di tempat yang perlu (kenapa, bukan apa), dan kendalikan ralat di sempadan (input pengguna, API, fail).
4. Uji: jalankan kod / ujian / lint jika boleh. Laporkan keputusan sebenar.

## Format jawapan
- Ringkasan pendekatan (2–3 ayat)
- Kod lengkap (atau perubahan pada fail dalam repo)
- Cara jalankan / contoh penggunaan
- Keputusan ujian dan had yang diketahui
