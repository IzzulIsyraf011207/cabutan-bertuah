# Presentation Maker (Prompt #13)

Prompt asal: "Create a professional slide-by-slide presentation on [your topic] with key points and speaker notes."

## Langkah
1. Kenal pasti topik, audiens, tujuan (memaklum, meyakinkan, mengajar), durasi dan bilangan slaid (lalai 10–12).
2. Satu slaid = satu idea. Maksimum 3–5 bullet pendek setiap slaid.
3. Jika jenis artifak Slides atau skill `pptx` tersedia dan pengguna mahukan fail, gunakannya; jika tidak, beri rangka teks.

## Format jawapan
Untuk setiap slaid:
- **Slaid N — Tajuk**
- Poin utama (bullet)
- Cadangan visual (carta, gambar, ikon)
- **Nota penceramah** (apa yang perlu disebut, 30–60 saat)

Struktur lalai: Tajuk → Masalah/konteks → Poin utama → Bukti/data → Penyelesaian → Ringkasan → CTA/Soal jawab.
