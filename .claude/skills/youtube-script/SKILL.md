# YouTube Script (Prompt #8)

Prompt asal: "Write a compelling YouTube video script on [your topic] with a strong hook, key points, and a call to action."

## Langkah
1. Tentukan topik, audiens, durasi (Short ≤ 60 saat atau video panjang) dan matlamat (views, subscribe, jualan).
2. Hook dalam 5 saat pertama: janji hasil, soalan, atau kenyataan mengejutkan.
3. Isi: 3–5 poin utama, setiap satu dengan contoh/cerita. Tambah "pattern interrupt" setiap 30–60 saat untuk video panjang.

## Format jawapan
- **3 pilihan tajuk YouTube** + idea thumbnail (teks ≤ 4 patah perkataan)
- **Skrip** dalam jadual: Masa | Visual / B-roll | Dialog (VO)
  - Hook → Intro ringkas → Poin 1..N → Ringkasan → CTA (subscribe / komen / link)
- **Penerangan video** + 3–5 hashtag
- Anggaran durasi
