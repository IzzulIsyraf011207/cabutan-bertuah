# Custom Workflow (Prompt #18)

Prompt asal: "Create a complete step-by-step workflow to achieve [your goal] using the best tools and strategies."

## Langkah
1. Jelaskan matlamat akhir, tempoh, sumber (orang, bajet, tools sedia ada) dan kekangan.
2. Peta aliran dari mula hingga hasil: input → proses → output, dengan titik keputusan.
3. Pilih tools yang pengguna sudah ada dulu (Claude Code, skill dalam repo ini, GitHub, Metricool, Google Drive/Sheets, Supabase) sebelum cadang tools baru.
4. Tandakan langkah yang boleh diautomasi (rujuk skill `task-automation`).

## Format jawapan
- **Matlamat & ukuran berjaya**
- **Gambaran aliran** (senarai bernombor atau rajah ringkas)
- **Langkah terperinci** — jadual: Langkah | Tindakan | Tool | Siapa | Masa | Output
- **Templat / senarai semak** yang boleh diguna semula
- **Titik automasi**
- **Risiko & pelan sandaran**
