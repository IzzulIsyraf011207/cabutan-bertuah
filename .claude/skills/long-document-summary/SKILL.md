# Long Document Summary (Prompt #2)

Prompt asal: "Summarize this document with key points, action items, and a simple explanation."

## Langkah
1. Baca keseluruhan dokumen (untuk PDF panjang, baca ikut bahagian). Jangan ringkaskan apa yang belum dibaca.
2. Kenal pasti jenis dokumen dan tujuannya.
3. Ambil perkara utama, keputusan, angka, tarikh akhir dan siapa bertanggungjawab.
4. Tulis dalam bahasa yang pengguna guna (Bahasa Melayu jika pengguna tulis BM).

## Format jawapan
- **TL;DR** (1–2 ayat)
- **Perkara utama** (5–10 bullet, ikut kepentingan, rujuk halaman/seksyen)
- **Tindakan (action items)** — senarai semak: tindakan, siapa, bila
- **Penjelasan mudah** — terangkan macam kepada orang yang tiada latar belakang
- **Perkara perlu perhatian** (risiko, klausa penting, perkara samar)
